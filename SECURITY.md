# Security Policy

## Supported Versions

LIFE//FORENSICS is currently maintained as an active project on its default branch.

Security fixes are evaluated against the latest version available in the repository.

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for a security or privacy vulnerability.

Instead, report it privately to the project maintainer through the contact method listed on the maintainer's GitHub profile.

Include, when possible:

- A clear description of the issue.
- Steps to reproduce.
- Potential impact.
- Relevant affected files or components.
- A proposed mitigation, if you have one.

Please do not include real private datasets, passwords, tokens, API keys, or other secrets in the report.

## What to Report

Security reports may include:

- Credential or secret exposure.
- Authentication or authorization weaknesses.
- Unsafe handling of uploaded data.
- Privacy leakage.
- Injection vulnerabilities.
- Dependency vulnerabilities with meaningful project impact.
- Unexpected exposure of sensitive information.

## Responsible Disclosure

Please give the maintainer reasonable time to investigate and address a vulnerability before publicly disclosing technical details.

Thank you for helping keep LIFE//FORENSICS safe.
